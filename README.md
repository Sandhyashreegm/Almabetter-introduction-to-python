# Introduction to Computer Programming Using Python

## Project Overview
This project contains practical Python programming exercises completed as part of my AlmaBetter learning program. The exercises helped me understand programming fundamentals and develop logical problem-solving skills.

## Objectives
- Understand Python syntax and programming fundamentals.
- Practice variables, data types, and operators.
- Apply conditions, loops, and functions to solve problems.
- Work with Python data structures.
- Understand object-oriented programming and exception handling.

## Topics Covered
- Python Data Types and Operators
- Indexing and Slicing
- Built-in Functions and Methods
- Conditional Statements and Loops
- Functions and Lambda Expressions
- List Comprehensions and Data Filtering
- Object-Oriented Programming (OOP)
- Exception Handling
